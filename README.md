# Calculadora de Interés Simple

Este proyecto contiene un script en Bash diseñado para calcular el interés simple a partir de un capital inicial, una tasa de interés anual y un período de tiempo en años.

## Descripción del Proyecto
El objetivo principal es ofrecer una herramienta ligera de línea de comandos para realizar cálculos financieros rápidos de interés simple.

## Uso
Para ejecutar el script en un entorno Unix/Linux:

```bash
chmod +x simple-interest.sh
./simple-interest.sh
